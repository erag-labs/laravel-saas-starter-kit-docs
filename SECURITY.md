# Security Policy

## Supported versions

Only the live website at [saas-laravel.com](https://saas-laravel.com) and the latest version of each SaaS Laravel starter kit receive security fixes. Weekly updates are pushed to the kit repositories, so please update to the latest version before reporting.

| Component | Supported |
| --- | --- |
| saas-laravel.com (this repository) | ✅ |
| Vue, React and Svelte starter kits — latest `main` | ✅ |
| Older copies of a kit that have not been updated | ❌ |

## Reporting a vulnerability

**Please do not report security vulnerabilities in public issues, discussions or pull requests.**

Report them privately in one of these ways:

- **GitHub:** use **Security → Report a vulnerability** in this repository.
- **Email:** erag.office@gmail.com, with the subject `Security: <short summary>`.

Please include:

- The affected component (website, or the Vue, React or Svelte kit) and its version or commit.
- A description of the issue and its impact.
- Steps to reproduce, or a proof of concept.
- Any suggested fix, if you have one.

## What to expect

- We acknowledge your report within **3 business days**.
- We send an initial assessment within **7 days**.
- We keep you updated while we work on a fix, and let you know when it is released.
- With your permission, we credit you once the fix is published.

Please give us reasonable time to fix the issue before disclosing it publicly.
