Multi-tenancy

A separate database for every tenant

Create a tenant and the kit provisions its database, runs tenant migrations, seeds roles, permissions and menus, then creates the primary administrator.

  • Subdomain identification on <sub>.APP_DOMAIN
  • Workspace status: Active, Trial, Pending Invitation, Suspended
  • Signed invitation link for the tenant admin, with resend
  • Admin password reset by email link or set manually
  • Tenant list with search, status filter and stats
  • Tenant profile: industry, team size, work week, registration and tax numbers

Developer experience

Clone it. Run it. Ship it.

Designed for Laravel Herd with *.test domains and wildcard subdomains, so tenant workspaces work locally without extra setup.

Two commands to run

composer setup installs everything and builds assets. composer dev starts the server, queue, logs and Vite together.

Typed routes and data

Wayfinder generates route functions in resources/js; Spatie Data classes are transformed into TypeScript types.

One command to verify

composer test runs linting, type checks and the Pest suite. composer lint fixes style across PHP and TypeScript.

Agent-friendly codebase

Laravel Boost ships guidelines and skills so AI coding agents understand the project from the first prompt.

~/code/my-saas
# install dependencies, create .env, migrate, build
$ composer setup
✓ Application key set
✓ Migrations complete
✓ Assets built

# server + queue + logs + vite
$ composer dev

queue  Processing jobs from the [default] queue
logs   Tailing application logs
vite   VITE ready — local dev server

# lint, type check and run the Pest suite
$ composer test

Billing

Payment Gateway — Your Choice

Payment integration is intentionally not included in the starter kit because every SaaS product has different payment requirements, countries, currencies, pricing models, and preferred providers.

Instead of forcing a specific provider, the starter kit keeps the billing layer flexible so developers can integrate the gateway that best fits their business.

  • No payment gateway lock-in
  • Choose your preferred provider
  • Implement subscriptions or one-time payments as needed
  • Keep the core starter kit clean and flexible
